# Security policy

Do not report exploitable vulnerabilities in public issues. Until a private security contact is configured, contact the repository owner directly through the private contact method listed in the GitHub repository profile.

Security-sensitive areas include authentication, friend sharing, public character discovery, memory retrieval, file import/export, plugin execution, camera/microphone permissions, API keys, spatial maps and generated assets.

All plugin execution and agent tool access must be least-privilege, explicit and auditable. Never run untrusted plugin code or model-generated shell commands without validation and sandboxing.

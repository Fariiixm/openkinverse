# Architecture Decision Records

- `ADR-0000-template.md` is the template. Copy it; do not edit it to record a decision.
- Real decisions start at `ADR-0001` and use `ADR-NNNN-short-title.md` (four-digit, zero-padded, sequential, never reused).
- `ADR-0001` is reserved for the platform and runtime decision (`ADR-0001-platform-and-runtime.md`; see `FIRST_PROMPT.md`).
- New ADRs start with status `Proposed` and change to `Accepted` when the engineering lead accepts them under the autonomy policy in `CLAUDE.md`. The owner may override any ADR. Superseded ADRs are kept and marked `Superseded by ADR-NNNN`.
- Write ADRs in professional English.
